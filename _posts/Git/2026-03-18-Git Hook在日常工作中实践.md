#### 背景：
git 钩子，是允许用户在使用 git 过程中在执行指定操作时执行预先设置的特定程序。官方文档：[githooks](https://git-scm.com/docs/githooks)。笔者对日常工作中对 git 的使用进行了相关调研，利用 git 提供的钩子能力，编写了一些指定特定功能的脚本。皆在提升日常工作中的效率。

笔者已经将项目开源，详见：[git-hook](https://github.com/liuhaoduoduo/git-hook)
